About this data

This is a user research prototype of a Power BI report for regulators. It shows Receipt of Waste data from Digital Waste Tracking (DWT), the service that receiving sites use to record the waste they accept. All names, permits and figures are invented.

Where the data comes from

Each record is one movement: one load of waste received at a permitted site. The receiving site submits it to DWT through its own software or by uploading a spreadsheet, and is expected to do so within 2 days of receiving the waste.

How up to date it is

The report is refreshed every day. If a site has not submitted, it has no movements for that period. The Receiver Submission Activity report (R-04) shows sites that have stopped submitting.

The data assurance checks

Checks such as estimated weight or a missing disposal or recovery code are worked out from fields sites already submit. Sites do not enter anything extra for them. The thresholds are placeholders for us to test with you.

Terms used

Movement
One load of waste received at a site.
EWC code
European Waste Catalogue code: the six-digit code that describes the waste. Codes ending in an asterisk (*) are hazardous.
Mirror entry
A pair of EWC codes for the same kind of waste, one hazardous and one not. Which applies depends on an assessment of the waste.
Disposal or recovery code
What the site does with the waste, for example R13 storage or D10 incineration.
Persistent organic pollutants (POPs)
Long-lasting chemicals, found for example in some upholstered seating and electrical equipment. Waste containing them generally has to be destroyed.
Hazardous property (HP) code
Describes why a waste is hazardous, for example HP14 ecotoxic.
Carrier registration (CBD)
The carrier, broker or dealer registration number of the business that moved the waste.
Estimated weight
The receiving site estimated the weight instead of weighing the load, for example from the container size or a typical load. Estimates are allowed, but they are less precise than a weighbridge reading.

What is new in version 1.1

  • A date range, with From and To dates and shortcuts. For a month or less, the chart shows one bar per day.
  • Weights in tonnes or kilograms.
  • "Filters" instead of "slicers", and terms spelled out instead of acronyms.
  • Movements without carrier registration details shown by weight (the default) or by movements.
  • EWC code names when you hover over a code.
  • An explanation of estimated weight, and a clearer explanation of the chart.
  • Smaller weight bars, and fewer columns in the receiving sites table so its buttons stay in view on the right.
  • Time of receipt, the waste description and any broker or dealer on each movement.
