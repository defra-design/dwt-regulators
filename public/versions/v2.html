Mural recommendations, November 2026

A design mock-up for discussion with the team, not for research. It applies the interaction and content design recommendations from the Mural board to all 4 reports. The notes were on R-01, R-02, R-03 and R-04, and most apply to every report.

Date of last change: 12 November 2026
User research status: Not for research

Design rationale

  • The minimum font size note said 16pt. We used 16px, which is 12pt in Power BI. 16pt (about 21px) would not fit a dashboard.
  • We chose "filters" because it's plain English. Power BI calls them slicers, but users don't see that word.
  • Data colours come from the Analysis Function colour guidance: dark blue for non-hazardous, orange for hazardous and dark pink for POPs, in every report.
  • To stop sideways scrolling, some columns were dropped from summary tables. They're still on the drill-through pages. For example: Nations in the R-02 carriers table, Region and Method in the R-04 receivers table, and per-code estimated weight on Site detail. Check that the team agrees.
  • Thresholds are the existing placeholders (for example 30% estimated weight and 35% missing D&R code). They still need agreeing with regulators.

To check with a Power BI developer

  • Cells that stack 2 or 3 values (such as site, organisation and permit) need a matrix or a combined text measure in Power BI.
  • Card labels that change between singular and plural need a measure (DAX) for each label.
  • Selecting an EWC code on one page and seeing results on another page needs drill-through.
  • R-04 has 8 pages, so its page tabs will scroll in Power BI.
  • The R-02 carrier map needs a map visual, which may be turned off in Defra's Power BI settings.

Not changed yet

  • Some "i" icons on summary cards still show information only on hover. Keyboard and screen reader users can't reach it (WCAG 1.4.13).
  • Region names keep their regulator prefixes, such as "EA:" and "SEPA:", and "DWT national" is not explained.
  • Filter values that come from the data, such as "Contains POPs", keep their abbreviations.
  • The EWC code charts in R-01 and R-03 use the full Analysis Function palette, so orange and dark pink also appear for ordinary EWC codes. This gives one colour 2 meanings.

Research questions

Questions from the Mural board to explore in a future round of research.

  1. Do users understand what "slicers" are, or do they recognise "filters" more easily?
  2. Do users mind units being abbreviated, for example "t" for tonnes?
  3. Do users understand abbreviations such as CBD, EWC, D&R and POPs without them being spelled out?
  4. Do users understand terms like "bucket size"? Is it a waste term or a dashboard term to them?
  5. Is it clear that the filters at the top affect all the data on the page, and now every page in the report?
  6. Do users know what the asterisk after an EWC code means?

Questions raised while making this version:

  1. Do users find it easier to move between report pages than to scroll one long page?
  2. Do users miss the columns that were dropped from the summary tables?
  3. Are the placeholder thresholds right for regulators?
